## 八、账号权重低时的养号建议（第一期前 4–8 周）

> 权重低时：**稳定露出 > 爆款幻想**；**互动 > 外链引流**；**原创完整页 > 群发搬运**。  
> 目标不是立刻涨粉，而是让系统认为你是「会持续发、有人读、不违规」的号。

### 8.1 三渠通用原则

| 原则 | 做法 |
|---|---|
| 先像真人 | 头像、简介、置顶/About 写清「写什么 + 更新频率」，三渠人设一致 |
| 节奏稳 | 宁可用「周更固定日」也不要一周连发 5 篇再消失两周 |
| 前 8 周少导流 | 外链（个人站、工具站、互推）控制在文末 1 个以内；勿全文广告味 |
| 先互动再发文 | 每天 10–20 分钟逛同话题：认真评论别人，再发自己的 |
| 系列可见 | 用「第 X 篇 / 系列名」降低跳出；让回访者形成预期 |
| 不追热点硬蹭 | 权重低时蹭烂热点易被判低质；用系列深度更稳 |

**产能上限（养号期）**：三渠合计建议 **每周 2–3 篇露出**（例如：公众号 1 + 博客园 1 + dev.to 隔周 1），不要为了「喂满三个平台」日更。

### 8.2 微信公众号

| 阶段 | 建议 |
|---|---|
| 资料 | 名称好记；简介含「AI / 术语 / Vibecoding」等关键词；头图统一 |
| 节奏 | **固定日周更 1 篇**（如每周二）；前 4 周不要日更 |
| 内容 | 优先发**已写好的术语总览/拆词**（完成度高、阅读门槛低）；单篇控制在易读长度，少贴长代码 |
| 互动 | 开留言（若有），每条有价值留言都回；文末固定问 1 个简单问题 |
| 安全 | 避免集中诱导分享/关注；不群发互推链接网；原创声明打开 |
| 观察 | 看「打开率 / 分享」而不是粉丝数；连续 4 周有稳定打开即可加第 2 栏目 |

**养号期勿做**：一天多推、纯转载、大段外链墙、标题党后正文空。

### 8.3 博客园

| 阶段 | 建议 |
|---|---|
| 资料 | 完善园子简介；申请博客、选好分类（AI / 面试 / 架构） |
| 节奏 | **周 1 篇面试题**即可；质量明显优先于数量 |
| 内容 | 标题直白：`Agent 面试｜…`；正文结构固定（考察点→答→追问）；配 1 张结构图 |
| 互动 | 每天逛首页/新闻，给同领域博文写**具体技术评论**（别只「写得好」）；回复自己文下评论 |
| 曝光 | 认真填标签；系列用博客园「分类/归档」；可参与相关征文但别硬套 |
| 外链 | 前几周文末最多一个「系列目录」；工具站链接先不加或极克制 |

**养号期勿做**：搬运拼接、无代码空谈、短平快灌水冲积分。

### 8.4 dev.to

| 阶段 | 建议 |
|---|---|
| 资料 | Cover image 统一；bio 写清 series；加 GitHub / 站点（站点可后加） |
| 节奏 | **双周 1 篇** Context Engineering；比周更更易维持英文质量 |
| 标签 | 固定组合如 `#ai` `#productivity` `#webdev`（选准 4 个以内，勿堆 10 个） |
| 互动 | 每天读 3–5 篇同 tag，留**可讨论的技术评论**；关注并回关真诚互动者 |
| 系列 | 用 DEV Series 功能把 Context 串起来，利于回访 |
| 曝光 | 发布后 1 小时内自己别狂刷；把精力放在回复评论 |

**养号期勿做**：同一天连发多篇、全文跨站重复无改写、评论区贴推广链。

### 8.6 何时算「养号过关」、可以加码

同时满足再考虑加推送密度 / 加重外链 / 上工具站 SEO 系列：

- [ ] 任意一渠出现**稳定自然阅读**（不是只靠自己点）连续 ≥ 4 周  
- [ ] 评论区开始有**陌生人提问**（不只互评好友）  
- [ ] 发文节奏已坚持 ≥ 8 周未断更  
- [ ] 无违规警告、无异常限流感（公众号打开未断崖）

未过关前：**把系列写深，比多开渠道更重要。**
