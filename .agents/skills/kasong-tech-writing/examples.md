# 结构模板与标题示例

以下模板只学**结构**。括号内换成你自己的题材；不要复用卡颂原文案例。

---

## A. 热点解读（公司 / 工具 / 版本）

**标题配方**

- `关于 X，你需要知道的`
- `耗时…，这个工具会…么？`
- `Y 团队终于妥协了...`

**骨架**

```markdown
大家好，我是{自称}。

{热点何时发生、一句话是什么}。

{读者会关心的 2～3 个具体问题}？

本文让我们详细来聊聊。

## {对象}是什么 / 版图

{愿景或目标一句话}

{横向能力 / 纵向链条 — 用列表}

## {迭代策略或历史动机}

{为何现在做：技术窗口 + 组织/商业原因}

{前辈同类项目：成了什么、败在什么}

## {会不会成 / 对你的影响}

{成功条件}
{风险与边界}

## 总结

{收回 3 点判断}
```

## B. 趋势预测

**标题配方**

- `预测{年份}之后的{领域}…`
- `从 {爆点} 看{年份}{领域}的一个小趋势`
- `{项目} 预示着…的未来`

**骨架**

```markdown
大家好，我是{自称}。

{爆点有多热 — 一句生活化观察}。

这对{读者身份}意味着什么？本文尝试预测…，原则如下：

- 尊重已有技术客观规律，不建立在假想突破上
- 尊重人性：再强的模式，让从业者赚不到钱就难推广

## {分析坐标系：范式 / 阶段 / 压缩…}

{用对比讲清：为何旧范式被接受、反例为何失败}

## {阶段 1 / 2 / 3}

每阶段：现象 → 机制 → 对岗位的含义

## 总结

{趋势一句话}
{对读者：机遇与挑战各一句}
```

**可带走框架示例（自造，勿抄原句）**

- 提效 × 门槛
- 迁移中 → 新栈成型 → 新职业路径
- 表达介质从代码转向提示词（若题材相关）

## C. 学习痛点

**标题配方**

- `为什么我总学不好 X？`
- `{口语抱怨}，{对象}好难懂`

**骨架**

```markdown
大家好，我是{自称}。

有没有人和我一样，学 X 的步骤是：

- 步骤 A
- 步骤 B
- 最终退化成错误用法

痛定思痛后我发现，问题不在努力，而在{错误坐标系}。

## 学不好的原因

{流行说法哪里对、哪里把人带偏}

## 一个例子

{先按错误坐标系「理所当然」地推}
{再展示正确坐标系下的反直觉结果}

## 正确心智模型

{类比 + 正式定义}
{之后怎么学 / 怎么用}

## 总结

{一句话换坐标系}
```

## D. 职业 / 焦虑

**标题配方**

- `最近看到太多 {X} 带来的焦虑，有些话想说`
- `保守点，N% 的…不适合…`
- `{身份}选择{动作}`（谨慎用，避免消费他人人设）

**骨架**

```markdown
大家好，我是{自称}。

{焦虑现象：谁、因什么工具/新闻}。

焦虑往往来自两种视角错位：

- 用发展视角看技术
- 用静止视角看自己的工作

## {行业会经历的 N 个阶段}

{阶段模型}

## 对焦虑的重述

{把「会被取代」改写成「栈会更新」或你的判断}

## 适合谁 / 不适合谁

{冷静标准，避免鸡汤}

## 总结

{可执行的下一步，1～3 条}
```

## E. 反常识揭秘

**标题配方**

- `都用 {安全的东西} 了，还能 {坏事}？`
- `{数字}…却…？`

**骨架**

```markdown
大家好，我是{自称}。

{日常困惑小故事或群聊场景}。

实际上，即使{表面保障}，仍可能因{分层}暴露信息，比如：

- 原因 1
- 原因 2

本文将聚焦在{协议/机制本身}，聊聊{标题里的矛盾}如何成立。

## {基础概念}

{HTTPS = … 这类短定义}

## {关键机制}

{握手 / 扩展字段 / 明文阶段…}

## {如何缓解 / 边界}

## 总结

{记住一句：加密 ≠ 元数据也加密}
```

## 标题改写练习（示意）

| 弱标题 | 更接近卡颂钩子 |
|--------|----------------|
| 浅谈前端 AI 编程 | 从 {某模型} 看 26 年前端的一个小趋势 |
| ESLint 与 Prettier 如何选型 | 格式化之争终于有官方答案了... |
| TypeScript 学习指南 | 为什么我总学不好 TS？ |
| Cursor 使用体验 | 最近看到太多 Cursor 带来的焦虑，有些话想说 |
| React 19 新特性汇总 | 关于 React 19，你需要了解的前因后果 |

## 语气对照（写时自检）

| 更像卡颂 | 不太像 |
|----------|--------|
| 短段、口语、敢下判断 | 长段堆定义、面面俱到无立场 |
| 先框架后细节 | 先 API 后故事 |
| 「这意味着…」「本质上…」 | 「众所周知」「毋庸置疑」压人 |
| 承认主观偏见 | 假装绝对客观又空洞 |
| 收束到从业者利益 | 收束到空洞「一起学习进步」 |
