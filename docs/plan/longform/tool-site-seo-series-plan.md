# 工具站 / Programmatic SEO 实战 · 总规划

> ⏳ **候选系列 · 待二次筛选**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> 与 Solopreneur（商业叙事）、新站案例（拆别人）互补：本系列讲 **自己怎么建可搜索的工具矩阵**。
>
> 姊妹系列：`solopreneur-series-plan.md` · `geo-ai-visibility-series-plan.md` · `new-site-case-studies-series-plan.md`
>
> 本系列定位：用免费工具 / 目录 / 长尾词做流量的独立开发者  
> 核心承诺：每篇对应一个可落地的站点动作（路由、模板、内容块、内链）  
> 风格锚点：问题 → 反模式（scaled content / doorway）→ 正确做法 → 检查清单，2000–3500 字/篇  
> 发布平台：个人博客（主）· 掘金 · Indie Hackers（英文精选）· X  
> 规模：5 幕约 **24 篇**
