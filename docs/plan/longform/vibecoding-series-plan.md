# 小白 Vibecoding 系列 · 总规划

> ⏸ **本期 P1 候选**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> 启动时先做 Act 1–2（10 篇）；与 100-skills / 新站案例日拆 **三选一**。适合拆小红书图文。
>
> 姊妹系列：`ai-series-plan.md`（AI 原理 · 面向开发者）  
> 本系列定位：**一行代码都没写过的人**，靠自然语言 + 浏览器 AI 工具，做出能发给朋友用的东西  
> 核心承诺：不装环境、不看代码、不学语法，也能出成品  
> 风格锚点：生活类比开头 → 全屏截图流程 → 可直接照抄的 Prompt 模板 → 一个能发给朋友的链接，2000-3000 字/篇  
> 发布平台：个人博客（主） · 公众号 · 小红书（拆图文） · 知乎  
> 规模：6 幕约 39 篇（本期若开只认 10 篇）

---

## 读者画像

| 项 | 内容 |
|---|---|
| 是谁 | 产品 / 设计 / 运营 / 学生 / 想搞点副业的普通人 |
| 会什么 | 会用电脑、能装浏览器插件、能注册账号 |
| 不会什么 | 一行 HTML / JS / Python 都没写过，看到终端会退出 |
| 想要什么 | 30 分钟内做出个东西发给朋友、发个朋友圈 |

## 工具主线（浏览器优先）

| 工具 | 场景 | 门槛 |
|---|---|---|
| **Bolt** | 全栈 Web App，一键部署 | 注册即用 |
| **Lovable** | 全栈 Web App，中文友好 | 注册即用 |
| **v0** | 单页 / 组件 / UI 原型 | 注册即用 |
| **Replit Agent** | 需要后端 / 数据库的项目 | 注册即用 |
| **ChatGPT / Claude 网页版** | 写脚本、改 Prompt、答疑 | 注册即用 |

后期（Act 6）才引入 Cursor / Claude Code 作为进阶。前 35 篇不需要打开终端、不需要装 Node / Python、不需要用 Git。
