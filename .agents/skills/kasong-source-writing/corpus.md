# 语料说明：React技术揭秘

来源：[https://react.iamkasong.com/](https://react.iamkasong.com/)（卡颂，《React技术揭秘》）

本文件只记录**结构地图与风格观察**，写作时禁止复述原文段落。

## 全书宗旨（前言原意转述）

- 目标：严谨、易懂的 React 源码分析教程
- 行文：不预设观点（锚定核心团队公开分享）、丰富参考资料、跟随版本更新
- 路径：理念 → 架构 → 实现 → 代码（自顶向下、抽象递减）
- 刻意不从日常 API 切入，避免陷入源码细节海洋

## 章节地图（风格取样用）

### 理念篇

| 章 | 代表写法 |
|----|----------|
| React 理念 | 官网理念 → CPU/IO 双瓶颈 → 时间切片 / Suspense → 共通结论「同步变可中断异步」 |
| 老/新架构 | 对比式铺陈 |
| Fiber 心智模型 / 实现原理 / 工作原理 | 一词多层含义；起源→含义→结构；注意框标优先级模型重构 |
| 前置知识 | 文件结构、调试、JSX |

### 架构篇

| 章 | 代表写法 |
|----|----------|
| render 流程概览 | workLoop 同步/并发对比；「递」「归」；调用序列列表；递归心智模型简化版 |
| beginWork / completeWork | 从传参看执行；mount/update 二分；effectTag 思想实验 |
| commit 各阶段 | 阶段切片讲解 |
| 双缓存 | 先外部类比（canvas）再映射到 current / workInProgress |

### 实现篇

| 章 | 代表写法 |
|----|----------|
| Diff 概览 | 四对象澄清；O(n³) 瓶颈 → 三条限制；入口按类型分流 |
| 单/多节点 Diff | 限制条件推复用；习题巩固 |
| 状态更新 | 流程概览 → 心智模型 → 结构 → 优先级 → 再落到具体 API |
| Hooks | 先设计理念（使用者 vs 开发者视角）→ 极简实现 → 数据结构 → 各 API |
| Concurrent | Scheduler、lane；部分章节标记进行中 |

## 风格指纹（观察摘要）

1. **教师带读**：我们 / 下一节 / 现在还不需要学 X
2. **设问驱动**：因何而来、究竟做了什么、如何解决
3. **强分类**：三层含义、两类瓶颈、递与归、单节点与多节点
4. **代码骨架化**：省略函数体，注释按含义分组
5. **例子走读**：极简组件 → Fiber 树 → 编号调用序
6. **注意框**：版本坑、命名原因（如 return）、特殊优化
7. **章末钩子 + 参考资料**：演讲、文章、源码文件
8. **语气**：严谨克制，偶尔生活化类比；少断言、少焦虑钩子
