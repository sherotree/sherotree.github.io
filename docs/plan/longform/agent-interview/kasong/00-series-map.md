# 背 57 道 Agent 面试题之前，你需要先换一套坐标系

> 文风版本：**卡颂向**（对照原文 [`../00-series-map.md`](../00-series-map.md)）

大家好。

最近招人的 JD 里，Agent Engineer、LLM Application 出现的频率，已经高到有点烦。

烦的不是岗位本身。

烦的是：很多人把「调过 ChatGPT、接过一次 Function Calling」写进简历，面试时却讲不清自己做的到底是不是 Agent（智能体）。

明明项目名叫 Agent，白板上一问控制权在谁手里，场面就开始沉默。

本文不讲某个框架怎么装。

本文把整季 57 题的地图摊开：这系列写给谁、每篇怎么用、两周内要面试该先刷哪几题。

原则就一条：尊重面试官真正在筛的东西——判断力，不是形容词。

## 这系列不适合「背完就能过」的人

适合你，大概是这几类：

- 做过后端 / 全栈，最近往 AI 应用转
- 调过 API，写过 Prompt（提示词），搭过一点 RAG 或 Tool Calling
- 马上要面，或半年内会面这类岗

不适合你，我也直说：

- 还没写过一行模型调用：先做两个小项目再回来，性价比更高
- 只想背名词：这里会反复追问「你会怎么设计」
- 指望包过、内推话术：没有

岗位名字各地乱起。你看到 JD 里同时出现 Tool Calling、RAG、Eval、沙箱、成本，基本都在这 57 题覆盖里。

## 坐标系：过关 / 加分 / 翻车

市面上很多「Agent 面试题」停在名词解释。

那是错误心智模型。

面试现场更像三层：

1. **过关**：机制讲得清，边界画得出
2. **加分**：有数字、有取舍、有你否决过的方案
3. **翻车**：空话、只会背框架名、项目叙事对不上白板

所以正题结构固定成闪卡，不是为了显得专业，是为了逼你对这三层。

```text
原题 → 考察点 → 过关答 → 优秀答 → 追问 → 翻车红旗 → 白板
```

用法也很现实：

1. 先闭卷答 5 分钟
2. 对过关答，看缺口
3. 再看优秀答和追问
4. 把红旗抄进自己的「禁用句」

你会发现，很多人不是不会做项目，是坐标系选错了：把「我用过 LangGraph」当成能力本身。

恰恰相反。框架是实现手段。控制回路才是能力。

## 12 个模块，本质是三次范式迁移

蓝区：把 Chatbot、Workflow、Agent 的控制权讲清，把工具循环跑顺。  
青区：评测、安全、账单——也就是「Demo 到生产」那道坎。  
橙区：系统设计 + 行为面，看你能不能在压力下做取舍。

| 模块 | 主题 | 题数 | 你会练到什么 |
|---|---|---|---|
| M1 | 基础概念与边界 | 6 | 是不是 Agent、何时不用、ReAct、采样、延迟 |
| M2 | Prompt / Context | 5 | System Prompt、Context Engineering、长上下文、缓存 |
| M3 | Tool Calling / MCP | 6 | 调用链路、schema、路由、失败与 HITL |
| M4 | RAG 与 Agent 检索 | 5 | Agent 场景下的检索、Chunking、评测 |
| M5 | 单 Agent 架构 | 5 | Coding Agent、终止条件、Planner、混合工作流 |
| M6 | Multi-Agent | 5 | 何时该拆、拓扑、上下文传递、失败隔离 |
| M7 | Memory / 长任务 | 4 | 记忆分层、checkpoint、队列与污染治理 |
| M8 | Eval / 可靠性 | 5 | 如何证明变好、离线在线、轨迹评测、回归集 |
| M9 | 安全与合规 | 4 | Injection、权限、沙箱、日志与 PII |
| M10 | 生产：成本 · 延迟 · 观测 | 5 | 估成本、路由、埋点、限流、多租户 |
| M11 | 系统设计整题 | 4 | Deep Research、客服、Coding 平台、Agent 网关 |
| M12 | 行为面 + 模拟 | 3 | STAR、和产品争论、45 分钟模拟 |

重申一下：这是面试向压缩，不是某框架教程。

答案会随模型和协议变。我会尽量写「判断」，少绑死某一家 API 的字段名。

## 怎么刷：三种人，三条路径

### 没面试，先打底

顺序：M1 → M3 → M5 → M8 → M9。

先练五块肌肉：边界、工具、单 Agent、评测、安全。其余穿插。

### 两周内要面试

别从行为面倒着背。优先这 8 题，差距最大：

1. 边界（什么是 Agent）
2. 何时不用 Agent
3. Function Calling 链路
4. Coding Agent 设计
5. 如何证明变好了
6. Prompt Injection
7. 成本估算
8. 客服 Agent 系统设计

### 已经在跑线上 Agent

直接从 M8～M11 开干，用你自己的事故当优秀答素材。

前面模块只用来校对口语，避免和行业说法对不上。

## 更新节奏（很现实）

博客园，分类建议「Agent工程师面试」。

每周三更：一 / 三 / 五。

对外标题可以更「判断句」，对内仍按第 N 题归档，方便收藏。

这个分析带偏见：我默认读者要的是过技术面，不是涨粉。

所以本系列会故意写翻车红旗。落进去不丢脸，那是复习点。

面试官想听的，通常不是「我用过某某框架」。
