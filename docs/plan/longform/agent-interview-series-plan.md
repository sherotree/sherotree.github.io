# Agent 工程师面试题 · 总规划

> ✅ **本季执行主线（博客园 only）** → 逐周发文表见 [`../cnblogs-agent-interview-calendar.md`](../cnblogs-agent-interview-calendar.md)  
> **节奏**：博客园每周 **3 篇**（一/三/五）；公众号 / dev.to 本季暂停。  
> 与 `ai-series-plan.md`（讲原理）、`tech-depth-series-plan.md`（讲落地）分工：本系列按**面试官视角**出题、给标准答、挖追问。
>
> 姊妹系列：`ai-series-plan.md` · `tech-depth-series-plan.md` · `100-skills-series-plan.md`
>
> 本系列定位：准备投 **Agent / LLM Application / AI Platform Engineer** 的工程师  
> 核心承诺：每题可当闪卡；答完知道「答到哪算过关、哪算优秀、哪算翻车」  
> 风格锚点：原题 → 考察点 → 参考答（分层）→ 追问 → 反例/红旗 → 可选白板图，1800–2800 字/篇  
> 发布平台：**博客园（主 · 本季唯一）**  
> 规模：12 模块 × **57 题**（题表为准；旧称 52 为加总笔误）

---

## 读者画像

| 项 | 内容 |
|---|---|
| 是谁 | 后端 / 全栈转 AI 应用；已有 LLM 玩具项目，要过正式面试 |
| 已经会 | Prompt、调过 API、搭过简单 RAG 或 Tool Calling |
| 想要 | 按面试轮次过一遍：概念 → 设计 → 生产 → 行为 |
| 不想看 | 只有名词解释、没有追问；或只有「背八股」没有场景题 |

### 目标岗位映射

| 岗位叫法 | 本系列覆盖重点 |
|---|---|
| Agent Engineer / AI Agent Engineer | 架构、工具、多 Agent、评测、安全 |
| LLM Application Engineer | RAG、Tool Calling、延迟成本、产品化 |
| AI Platform / Infra（偏应用侧） | 网关、观测、沙箱、评测基建 |
| 全栈 + AI | 系统设计题 + 落地权衡 |

## 每题结构模板

```
【原题】
面试官原话（中英可各一版标题）

【考察点】(3–5 条)
知识点 · 工程判断 · 沟通清晰度

【过关答】(核心 400–600 字)
Junior / Mid 能拿到 offer 的完整答法

【优秀答】(加分 300–500 字)
带数字、取舍、踩过的坑、和生产约束

【追问清单】(3–6 个)
Q1 … 期望答法要点
Q2 …

【翻车红旗】
常见错误答 / 空话 / 只会背框架名

【白板 / 示意】(可选)
一张架构草图或伪代码骨架（可折叠）

【关联】
链到 AI 系列 / 技术深度对应长文（有则链）
```

## M1 · 基础概念与边界（6 题）

| 序 | 题干 |
|---|---|
| 1.1 | 什么是 Agent？和 Chatbot / Workflow 的边界在哪？ |
| 1.2 | 什么时候不该用 Agent？举三个你否决 Agent 的场景 |
| 1.3 | ReAct 在做什么？和 Plan-and-Execute 怎么选？ |
| 1.4 | LLM 只是「下一个 Token 预测」——这对 Agent 设计意味着什么？ |
| 1.5 | Temperature / Top-p 在 Agent 工具循环里怎么设？为什么常接近 0？ |
| 1.6 | 解释 TTFT、TPS、端到端延迟——面试官问「慢」时你查哪一层？ |

## M2 · Prompt / Context Engineering（5 题）

| 序 | 题干 |
|---|---|
| 2.1 | System Prompt 里你会放什么、绝不放什么？ |
| 2.2 | 什么是 Context Engineering？和 Prompt Engineering 差在哪？ |
| 2.3 | Lost in the Middle / Context Rot：你怎么缓解？ |
| 2.4 | 结构化输出（JSON Schema / tool args）失败了怎么恢复？ |
| 2.5 | Prompt Caching 原理是什么？对 Agent 多轮调用账单有何影响？ |

## M3 · Tool Calling / MCP（6 题）

| 序 | 题干 |
|---|---|
| 3.1 | Function Calling 的完整链路（schema → 模型选择 → 执行 → 回填）画出来 |
| 3.2 | 工具描述写差会导致什么？给一个「好 schema vs 坏 schema」对比 |
| 3.3 | 工具过多时怎么路由？枚举、检索、分层专家怎么选？ |
| 3.4 | MCP 解决什么问题？和「自己写一堆 HTTP tools」比的优劣 |
| 3.5 | 工具执行超时 / 部分失败 / 幂等：你怎么设计？ |
| 3.6 | 人在环路（HITL）：哪些工具必须人工确认？产品怎么做打断？ |

## M4 · RAG 与 Agent 检索（5 题）

| 序 | 题干 |
|---|---|
| 4.1 | Agent 里的 RAG 和「问答机器人 RAG」有何不同？ |
| 4.2 | Chunking 策略怎么讲才像干过活的？ |
| 4.3 | 混合检索 + Rerank 的取舍；什么时候不用向量库？ |
| 4.4 | Agent 该「先检索再想」还是「边想边检索」？ |
| 4.5 | 如何评测检索质量（Recall@k、faithfulness）并接到 Agent eval？ |

## M5 · 单 Agent 架构（5 题）

| 序 | 题干 |
|---|---|
| 5.1 | 从 0 设计一个「能改 GitHub Issue 并开 PR」的 Coding Agent，讲组件 |
| 5.2 | 循环终止条件怎么设计？防死循环的硬限制有哪些？ |
| 5.3 | Planner 和 Executor 拆不拆？拆了的状态机怎么画？ |
| 5.4 | 浏览器 Agent vs API Agent：沙箱、观测、失败模式差异 |
| 5.5 | Workflow 编排（确定性）+ LLM 节点：混合架构何时优于纯 Agent？ |

## M6 · Multi-Agent / 编排（5 题）

| 序 | 题干 |
|---|---|
| 6.1 | 多 Agent 什么时候真有必要？什么时候是过度设计？ |
| 6.2 | 对比 Supervisor、Pipeline、辩论式：各适合什么任务？ |
| 6.3 | Agent 间怎么传上下文？传摘要 vs 传全量 vs 共享记忆 |
| 6.4 | LangGraph / CrewAI / AutoGen：你会怎么向面试官做选型（不站队品牌）？ |
| 6.5 | 多 Agent 的失败隔离与补偿：一个子 Agent 挂了怎么办？ |

## M7 · Memory / 状态 / 长任务（4 题）

| 序 | 题干 |
|---|---|
| 7.1 | Short / Long / Episodic / Working Memory 你怎么落地存储？ |
| 7.2 | 会话跨天恢复：checkpoint、线程 ID、幂等键怎么设计？ |
| 7.3 | 跑 30 分钟的 Agent 任务：队列、worker、取消、重放怎么做？ |
| 7.4 | 「记忆污染」和错误记忆写入：如何治理？ |

## M8 · Eval / 可靠性（5 题）

| 序 | 题干 |
|---|---|
| 8.1 | 如何证明改 Prompt / 换模型后 Agent「变好了」？ |
| 8.2 | Offline eval vs Online eval（影子流量、A/B）怎么配？ |
| 8.3 | 轨迹级评测（trajectory）和结果级评测差在哪？ |
| 8.4 | 幻觉、工具选错、权限越界：三类失败的监控指标 |
| 8.5 | 用一小套回归集讲清楚：你最少要有哪些 case？ |

## M9 · 安全与合规（4 题）

| 序 | 题干 |
|---|---|
| 9.1 | Prompt Injection：直接注入 vs 间接注入（网页/文档）怎么防？ |
| 9.2 | 工具权限最小化：OAuth scope、只读默认、二次确认 |
| 9.3 | 代码执行 / 浏览器沙箱：隔离边界你怎么画？ |
| 9.4 | 日志里能不能存完整 Prompt？PII 与审计怎么平衡？ |

## M10 · 生产：成本 · 延迟 · 观测（5 题）

| 序 | 题干 |
|---|---|
| 10.1 | 给一个 Agent 估成本：你会要哪些输入假设？ |
| 10.2 | 模型路由（小模型兜底 + 大模型升级）的触发条件 |
| 10.3 | 可观测性：trace、span、tool call、token 你埋哪些点？ |
| 10.4 | 限流、熔断、降级：Agent 特有的策略和 Chat 有何不同？ |
| 10.5 | 多租户 Agent 平台：配额、隔离、密钥管理怎么讲？ |

## M11 · 系统设计整题（4 题）

_每题可拆成「上篇框架 + 下篇深挖」；计 4 题额度_

| 序 | 题干 |
|---|---|
| 11.1 | 设计「公司内部的 Deep Research」：检索、引用、权限、评测 |
| 11.2 | 设计「客服 Agent」：工单、工具、升级人工、质检 |
| 11.3 | 设计「Coding Agent 平台」：多仓、沙箱、PR、成本墙 |
| 11.4 | 设计「Agent 网关 / 控制面」：路由、策略、观测、计费 |

## M12 · 行为面 + 模拟（3 题）

| 序 | 题干 |
|---|---|
| 12.1 | 讲一个你把 Agent Demo 推到「能给真实用户用」的故事（STAR） |
| 12.2 | 和产品争论「要不要上 Multi-Agent」时你怎么推进？ |
| 12.3 | 模拟面试：45 分钟脚本（开场自我介绍 → 2 道深题 → 反问清单） |
