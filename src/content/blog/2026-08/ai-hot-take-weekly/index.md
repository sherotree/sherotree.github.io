Google 在推出 Gemini 3 一代能力时，同步介绍了面向开发者的 agentic 开发平台 Google Antigravity：在熟悉的 AI IDE 体验之上，把 Agent 提升到更主的操作面，并强调可使用编辑器、终端与浏览器等工具完成端到端任务。

热点容易写成「又一个 Cursor 竞品」。对开发者更有用的，仍是三问：**是什么、怎么用、怎么选**。

![评估更新的三个问题](https://ik.imagekit.io/4pjac7gmxh/blog/2026/10/hot-take-three-q_TE19Cflqu.png)

## 一、是什么

据公开介绍，Antigravity 的要点包括：

（1）核心仍是 AI IDE 形态，降低迁移陌生感  
（2）Agent 拥有更明确的主表面，而不只是侧边聊天附件  
（3）Agent 可规划并执行复杂软件任务，并触达编辑器、终端、浏览器等  
（4）与 Gemini 3 的推理与工具使用能力绑定宣传

![Agent 同时使用编辑器、终端、浏览器](https://ik.imagekit.io/4pjac7gmxh/blog/2026/10/antigravity-agent-ide_pGq5LI2Rz.png)

一句话：把「人在 IDE 里偶尔叫 Agent」推进到「任务级 Agent 在 IDE 里办事，人做审查与决策」。

## 二、怎么调用 / 怎么跟进

（1）以 Google 官方发布渠道与文档开通预览/资格为准  
（2）开发者同时可关注 Gemini API / AI Studio / Vertex 上的 Gemini 3 能力，二者相关但不是同一产品面  
（3）落地时仍按工单写：目标、范围、约束、验收；工具越多越要边界

本篇不写逐步点击教程（界面会变），只定心智模型。

## 三、怎么选：要不要立刻换默认环境

更值得认真试用：

（1）你已在 Google 云与 Gemini 生态  
（2）任务天然需要浏览器验证 + 终端 + 多文件改动  
（3）你有评测集，能对比现有 Agent IDE

可以先观望：

（1）现有工具链已稳定，切换成本高于收益  
（2）合规要求工具链冻结  
（3）只是被发布会节奏推动，没有真实痛点

和 Cursor 等工具的关系：竞争会催熟「Agent 主界面 + 多工具」交互；对个人，保留评测与约束习惯，比站队品牌重要。

## 四、风险提醒

（1）Agent 自动开浏览器与终端，攻击面与误操作面上升  
（2）提示注入与不可信网页内容  
（3）演示任务成功率 ≠ 你的仓库成功率

## 五、小结

Antigravity 代表的趋势是：Agent 从插件变成 IDE 里的一等公民，并默认组合编辑器、终端与浏览器。按「是什么 / 怎么跟进 / 怎么选」评估，用评测集说话，比转发海报更接近工程。
