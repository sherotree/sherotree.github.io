# 每天拆解一个新站成功案例 · 100 天 · 总规划

> ⏸ **本期 P1 候选**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> 与 `100-skills` / Vibecoding **三选一**再开日更；勿与 Reddit 日更叠满。  
> 与 Solopreneur 强互补：本系列提供「别人怎么赢的」，出海线提供「我怎么做的」。
>
> 姊妹系列：`solopreneur-series-plan.md` · `100-skills-series-plan.md` · `vibecoding-series-plan.md` · `ai-series-plan.md`
>
> 本系列定位：**最近新近做起来的独立站 / AI SaaS / 工具站**，每天拆一个「为什么现在能火」  
> 核心承诺：不写软文、不吹估值；每篇给到可抄的选题 / 落地页 / 获客动作  
> 风格锚点：一个成功信号 + 产品一句话 + 拆解三板斧 + 我能不能抄，1500–2500 字/篇  
> 发布平台：个人博客（主） · X 中文圈 · 即刻 · 小红书（拆图） · 知乎  
> 规模：14 周 × 7 天 = 98 天 + 收尾 2 天 = **100 篇**

---

## 选站标准（进榜门槛）

站点必须同时满足至少 **2 条「成功信号」** + **1 条「新鲜度」**：

### 成功信号（任选 ≥2）

| 信号 | 例子 |
|---|---|
| 流量 | Similarweb / Ahrefs 可见跃升；公开 MAU / PV |
| 收入 | 公开 MRR / ARR；Stripe Atlas / IH 晒单；付费墙实测 |
| 社区 | Product Hunt 日榜/周榜靠前；HN 首页；Reddit 高赞；Indie Hackers 热帖 |
| 增长叙事 | 30–90 天内从 0 → 可感知规模（粉丝、waitlist、星标） |
| 可验证产品 | 能注册试用；不是只有落地页的 vaporware |

### 新鲜度（必须）

- 上线或「爆起来」发生在约 **近 12–18 个月**（优先近 6 个月）
- 或：老站但因**新关键词 / 新形态**（如 Agent、MCP、本地 LLM、垂直 AI）在近半年二次起飞

### 明确不进榜

- 纯大厂子产品（除非一人团队可抄的切片）
- 只有融资新闻、无产品形态
- 灰色擦边 / 无法复现合规路径的玩法
- 自己没打开过官网、没走完一次核心流程的站

## 每篇结构模板

```
【钩子】(150–200 字)
一个成功信号：数字 / 榜单位次 / 时间线（例：「上线 47 天，$8.2k MRR」）

【一句话产品】(100 字)
给谁 · 解决什么 · 怎么收费（或怎么变现）

【为什么是现在】(300–400 字)
时机：关键词 / 平台算法 / 技术成熟度 / 竞品真空
不是「产品好」空话，要落到可观察的外部条件

【拆解三板斧】(600–900 字)
1. 选题 / 定位：关键词或场景切口
2. 产品与落地页：信息架构、CTA、定价锚点（附截图）
3. 获客：首批用户从哪来（PH / SEO / 内容 / 社群 / 付费）

【可抄动作】(200–300 字)
读者今天就能做的 1–3 步（不是「去融资」）

【我会不会做同类】(150 字)
绿：值得跟 · 黄：可借鉴局部 · 红：别跟（说明理由）

【资料】(文末)
官网 · 公开数据来源 · 相关讨论帖链接
```

## 14 周排期（按赛道轮转，站名随周刷新）

具体站名**不预锁 100 个**（市场变化快）；每周日从「候选池」定下周 7 站。赛道轮转保证覆盖面：

```
Week 1   方法论 + 样本站怎么挑          Day 1–7
Week 2   AI 写作 / 内容工具              Day 8–14
Week 3   开发者工具 / AI IDE 周边         Day 15–21
Week 4   垂直行业 AI SaaS               Day 22–28
Week 5   设计 / 图片 / 视频工具           Day 29–35
Week 6   SEO / 目录站 / Programmatic     Day 36–42
Week 7   微 SaaS / 单一功能工具           Day 43–49
Week 8   本地优先 / 隐私 / 开源商业       Day 50–56
Week 9   Agent / MCP / 自动化            Day 57–63
Week 10  教育 / 职场 / 生产力             Day 64–70
Week 11  电商 / 独立站 / 创作者变现       Day 71–77
Week 12  中国出海 / 中文圈跑通的站        Day 78–84
Week 13  「翻车与假成功」对照样本         Day 85–91
Week 14  Meta：怎么自己建案例库           Day 92–98
Day 99   100 站横评：我的可抄 Top 20
Day 100  复盘：新站成功的 10 条可复用规律
```

### Week 1 · 入门（固定篇目）

| Day | 主题 |
|---|---|
| 1 | 什么叫「新站成功」：我用的 5 个信号（附打分表） |
| 2 | 去哪找样本：PH / HN / IH / Similarweb / X / 即刻 |
| 3 | 怎么读一个落地页：30 秒判断值不值得深拆 |
| 4 | 样本站 #1（本周赛道：内容工具）完整示范拆解 |
| 5 | 样本站 #2 |
| 6 | 样本站 #3 |
| 7 | 周复盘：3 站共同的获客动作 |

### Week 2–12 · 每日一站

每日标题格式：

`Day X｜<站名>：<成功信号一句话> —— <赛道标签>`

例：`Day 12｜Example.ai：$12k MRR in 60 days —— 垂直法律 AI`

### Week 13 · 对照样本（防鸡血）

| Day | 主题类型 |
|---|---|
| 85–87 | 「看起来很火但留不住」的站 |
| 88–89 | 「融到钱但产品没起来」 |
| 90–91 | 「抄了爆款却死掉」的共性 |

### Week 14 · Meta

| Day | 主题 |
|---|---|
| 92 | 我的案例库模板（Notion / 表格字段） |
| 93 | 如何用 AI 辅助拆站（Prompt + 截图流程） |
| 94 | 从拆解到自己的 idea：筛选漏斗 |
| 95–97 | 3 个「我会自己做」的方向深拆 |
| 98 | 开源一份「100 天案例索引」落地页构想 |

## 候选池来源（每周日更新）

| 来源 | 怎么用 |
|---|---|
| Product Hunt | 日榜 / 周榜；看 Maker 是否 indie |
| Hacker News | Show HN 高分 + 后续跟帖有收入线索 |
| Indie Hackers | Milestone 帖、$1k MRR 故事 |
| X / 即刻 | 「just hit」「shipped」「MRR」类帖 |
| Similarweb / Ahrefs | 流量跃升的新域名（辅助，不唯数据） |
| 中文圈 | V2EX / 即刻独立开发者 / 少数派相关讨论 |

维护一张表：`候选站 | 发现日 | 成功信号 | 赛道 | 状态（待拆/已拆/淘汰）`

## 日更 SOP（轻量）

| 时间 | 动作 |
|---|---|
| 前一天 20–40 min | 打开站、走完核心流程、截图、记成功信号来源 |
| 当天 40–60 min | 按模板成文 + 发博客 |
| 当天 +15 min | X thread / 即刻摘要 |
| 每周日 30 min | 刷候选池、锁下周 7 站、淘汰不合格 |

### 断更保险

- 预写缓冲：始终 3 篇存稿
- 降级日：只发「钩子 + 一句话产品 + 绿黄红」（短版），周末补全文
- 替补：每周多备 2 个候选站

---

## 敏感与诚信边界

- 一切收入 / 流量数字必须注明**来源**（官网、公开帖、第三方估算）；估算要写「估算」
- 不臆造 MRR；拿不到数字就写「未公开，改用榜单/社区信号」
- 竞品拆解保持尊重：可批评定位，不人身攻击 Maker
- 若站已关停：标明日期，改写「为什么熄火」对照篇
