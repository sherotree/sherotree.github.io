# 一人公司型系列 · 总规划

> ✅ **本期 P0 长文主线 A**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> **本期只做**：子系列 1 全 20 篇 + 子系列 2 精选 8 篇。子系列 3「副业不吹牛」→ P2 暂缓。  
> **短内容配对**：Reddit/IH Build in Public（S2）+ X 长文拆条（S3）。
>
> 姊妹系列：`ai-series-plan.md` · `vibecoding-series-plan.md` · `tech-depth-series-plan.md` · `tech-crossover-series-plan.md` · `new-site-case-studies-series-plan.md`
>
> 本系列定位：**打算靠自己（或极小团队）做出海产品、AI SaaS、独立副业**的开发者  
> 核心承诺：只讲我真实做过 / 花过钱 / 收到过账单的事，不喊口号不画饼  
> 风格锚点：每篇一个具体节点 + 真实数字 + 一次可复用的动作，2000-3500 字/篇

> 规模：3 个子系列共 45 篇（本期认 28 篇）

## 推进节奏

- **前 2 周**：出 1.1（为什么出海）+ 2.1（idea 来源）+ 3.10（我的真实账单），一次性铺出三条线的诚意
- **月度节奏**：子系列 1 每周 1 篇（100 天项目周更）；子系列 2 每两周 1 篇；子系列 3 每月 2 篇
- **每 5 篇**：整合成 PDF（「独立开发出海手册」/「AI SaaS 冷启动手册」）
- **每篇产出物**：正文 md + 图表 + 真实数字截图（打码敏感信息）

---

## 敏感边界

- 涉及真实收入 / 用户 / 流量数据的部分，只发博客不发公众号 / 小红书
- 竞品 / 客户信息一律脱敏
- 涉及税务 / 合规部分注明「个人经验，非专业建议」
