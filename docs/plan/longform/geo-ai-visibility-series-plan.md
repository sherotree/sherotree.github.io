# GEO / AI 搜索可见度 · 总规划

> ⏳ **候选系列 · 待二次筛选**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> 与传统 SEO、工具站系列互补：本系列专攻 **被 LLM / AI 答案引擎引用与推荐**。
>
> 姊妹系列：`tool-site-seo-series-plan.md` · `ai-series-plan.md` · `new-site-case-studies-series-plan.md`
>
> 本系列定位：想让站点出现在 ChatGPT / Perplexity / Google AI Overview 等答案里的站长与内容人  
> 核心承诺：每篇给可执行的页面改动清单，不空谈「E-E-A-T」口号  
> 风格锚点：一个可见度目标 → 页面改法 → 前后对照 / 案例 → 检查清单，2000–3000 字/篇  
> 发布平台：个人博客（主）· 掘金 · 知乎 · X · 英文可投 dev.to  
> 规模：4 幕约 **20 篇**
