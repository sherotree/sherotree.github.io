# AI / 开发者 Twitter 中文精选周刊（轻人工）计划

> 状态：待执行  
> 关联：[content-plan-3months.md](./content-plan-3months.md)、[chinese-blog-github-pages.md](./chinese-blog-github-pages.md)  
> 形态：链接 + 中文点评 + 为什么值得看（不做全文转载）  
> **来源硬约束：只从 Twitter/X 拉取**  
> **语言硬约束：只保留中文帖**（帖文主体为中文；英文帖、纯链接转发无中文说明一律不进候选池）  
> 原则：AI 扛流水线，人只做轻闸门；先周更、验证后再考虑日更或独立站

---

## 一、目标与定位

| 项 | 决定 |
|----|------|
| 产品 | **Twitter 中文精选周刊**：每周 8～12 条 AI / 开发者相关**中文推文/长帖**精选 |
| 数据源 | **仅 Twitter/X**（关注列表、列表 List、搜索/书签账号池） |
| 语言范围 | **仅中文帖**；拉取后强制语言过滤 |
| 单条结构 | 推文原链 + 一句话摘要 + 「为什么值得看」+ 可选标签 |
| 主目标 | 用可控人工成本试探流量与回访；**不**以「高流量独立站」为一期 KPI |
| 人耗预算 | 每周 **20～40 分钟**（扫候选 → 勾选/砍掉 → 发布） |
| 自动化目标 | 拉帖、去重、中文过滤、粗排、点评草稿、排版入库由 AI/脚本完成（约 80%～90%） |
| 与原创计划关系 | **副线栏目**，不替代六站原创「理解 X」主线；不与人设抢戏 |
| 首期载体 | 优先挂在个人博客 `/digest/` 或 `/weekly/`；**暂不**单独开站 |

**明确不做（首期）：**

- 非 Twitter 源（掘金/RSS/公众号等）作主源  
- 英文推文、机翻外网热帖当正文  
- 全文/大段粘贴推文或 Thread（只链原帖 + 短点评）  
- 未授权硬爬、破解客户端；日更、评论系统、用户投稿  
- 零审核全自动发布  
- 产品软广、自有工具导流（与内容计划纪律一致，除非另改）

---

## 二、为何这样定

- 信息差仍在 Twitter 中文 AI/开发者圈；「链接 + 点评」比全文搬运版权风险更低。  
- **只收中文帖**：读者与六站受众一致，点评无需翻译。  
- 日更对 API 额度与质检要求高；周更更匹配少人工。  
- 纯 AI 无闸门易收营销号、误读 Thread；轻审核是底线。  
- 先验证 4～6 期再决定是否加码。

## 三、内容规格

### 3.1 一期周刊

| 项 | 规格 |
|----|------|
| 节奏 | 每周固定日 1 期（建议周日或周一） |
| 条数 | **8～12**（宁缺毋滥，可少于 8，不超过 12） |
| 范围 | AI、开发者工具、工程实践、模型/开源动态；排除纯八卦与明显营销软文 |
| 形态 | 单帖或 Thread 均以**一条原链**呈现（Thread 链首帖） |
| 语言 | **帖文主体须为中文**；栏目文案全中文 |
| 文风 | 短、具体、少形容词；点评要有信息增量，禁止空泛「值得关注」 |

**中文判定（流水线硬过滤）：**

- 帖文文本汉字占比明显高于拉丁字母。  
- 中英夹杂：叙述主体为中文（术语英文可接受）→ 保留；整帖英文 → 丢弃。  
- 仅发英文链接卡片、无中文说明 → 丢弃。  
- 明显营销话术 / 互刷 → 人闸门优先砍。

### 3.2 单条字段

```yaml
title: 展示用短标题（可由首句或 AI 生成，中文）
url: https://x.com/{user}/status/{id}   # 或 twitter.com 等价链接
author: "@handle"
author_name: 显示名  # 可选
lang: zh  # 固定；非 zh 不得入库
published_at: 2026-08-01T12:00:00Z
metrics:  # 可选，拉取时快照，不编造
  likes: 0
  reposts: 0
  replies: 0
summary: 一句话说明讲了什么（≤80 字）
why_read: 为什么值得看（≤120 字，说清对谁有用/解决什么误解）
tags: [AI, 工具]  # 可选
editor_pick: false
```

### 3.3 页面形态

- `/digest/` — 周刊列表（按期倒序）  
- `/digest/2026-W32/` — 单期正文  
- 页底固定：「以下为 Twitter/X 中文帖精选与点评，非原文转载；版权与完整内容见原帖。」

## 四、流水线（AI + 轻人工）

```text
Twitter 拉取（账号池/List）→ 中文过滤 → 去重/合并 Thread
        → AI 粗排打分 → 人勾选 8～12 条（20～40min）
        → AI 写 summary / why_read
        → 人扫一眼事实与语气 → Markdown 入库 → 发布
        → （可选）改编发公众号/即刻一条导读
```

### 4.1 候选源（仅 Twitter/X + 仅中文）

配置放 `sources.yml`（或等价），人偶尔维护账号池：

1. **高信号中文作者** handle 列表（AI / 前端 / Agent / 开源向）  
2. 自建 **X List**（只收中文向账号）定时拉时间线  
3. （可选）关键词搜索：`AI OR Agent OR 大模型` 等 + 语言过滤（额度紧则首期不做）  
4. （可选）自己账号的 Bookmarks 导出作补充

**拉取方式（按合规优先）：**

| 优先级 | 方式 | 说明 |
|--------|------|------|
| 1 | X API（官方） | 付费/额度内拉取 List 或 user timeline；首选 |
| 2 | 半自动 | 人用官方客户端导出/复制候选链接清单，脚本只做去重与点评（API 未就绪时的降级） |
| 3 | 禁止 | 未授权爬虫、破解 App、批量绕过限制 |

首期若 API 成本高：**允许「人贴 20～40 条候选链接 + AI 过滤点评」** 仍算达标，人耗仍压在 40 分钟内（含挑选链接）。

### 4.2 AI 职责

| 步骤 | 输入 | 输出 |
|------|------|------|
| 语言过滤 | 帖文文本 | `lang=zh` 或丢弃 |
| 主题过滤 | 文本 + 作者 | 是否 AI·开发相关、是否像营销 |
| 排序 | 候选池 | 建议分 + 短理由（可参考公开互动数，不编造） |
| 撰写 | 入选帖文本（短摘或 Thread 要点） | `summary`、`why_read`、可选 `title` |
| 排版 | 条目 JSON | 一期 Markdown / MDX |

Prompt 约束：不编造阅读量/转发数；不确定写「未核实」；**不大段引用原帖**；点评必须回答「对谁有用」；英文帖直接 drop。

### 4.3 人的闸门（不可省）

1. 打开排序后的候选表（约 20～40 条）。  
2. 勾选 8～12；砍掉过时、重复、软广、非中文、断章 Thread。  
3. 扫点评：改胡话、空话；最多改 2～3 条。  
4. 发布；可选发一条中文平台导读。

## 六、成功标准（先跑 4～6 期）

| 指标 | 参考线 |
|------|--------|
| 稳定性 | ≥4/6 期按时发布；单期 8～12 条 |

## 七、执行清单

### 阶段 A：规格与账号池（约 0.5 天）

- [ ] 定栏目名（暂名：「推特中文精选」/「本周 X 值得看」；执行前敲定）  
- [ ] 定发布日与 URL（`/digest/YYYY-Www/`）  
- [ ] 写 `sources.yml`：≥15 个中文高信号 handle 或 1 个 X List  
- [ ] 选定拉取路径：官方 API **或** 首期「候选链接清单」降级  
- [ ] 写 Prompt（中文过滤 / 主题 / 排序 / 撰写）与 schema

### 阶段 B：最小流水线（约 1～2 天）

- [ ] 脚本：拉帖或读入链接清单 → 取文本 → **中文过滤** → 去重 → 候选 JSON  
- [ ] 模型：打分 + 写 `summary` / `why_read`  
- [ ] 输出一期 Markdown 草稿  
- [ ] 勾选方式：`selected: true` 或简单 CLI（不做后台）

### 阶段 C～E

- [ ] 博客栏目或临时 md 发布 + 页脚声明  
- [ ] 试跑 4～6 期，记录耗时 / API 额度 / 混入英文等异常  
- [ ] 验证通过后再考虑 RSS、独立站等放大项

## 九、风险与纪律

- **版权**：只链原帖 + 短点评；不大段粘贴。  
- **X ToS / 额度**：优先官方 API；禁止未授权爬取；额度不够就降级为半自动，不硬刚。  
- **语言 / 来源**：非中文、非 X 链接不得上发布页。  
- **事实**：人闸门盯「为什么值得看」是否胡扯、Thread 是否断章。  
- **同质化**：定期换账号池，避免总是同一批大 V。  
- **品牌**：避免「爆款搬运」话术，强调「中文圈精选与判断」。

## 十、一句话结论

从 **Twitter/X 拉中文 AI/开发者帖**，用 **AI 流水线 + 每周半小时勾选**，做成「原链 + 点评 + 为什么值得看」周刊栏目；先跑 4～6 期再决定是否加码。
