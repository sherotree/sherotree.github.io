# 技术破圈型系列 · 总规划

> ⏸ **本期 P2 暂缓正文系列**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）。  
> 本期最多把已有 P0 长文「拆成小红书图文」，不另写本系列 35 篇。
>
> 姊妹系列：`ai-series-plan.md` · `vibecoding-series-plan.md` · `tech-depth-series-plan.md`
>
> 本系列定位：**用小红书 / 公众号的语法说技术**，让懂技术的人破圈，让不懂技术的人愿意读  
> 核心承诺：每一篇都能拆成朋友圈截图 / 小红书封面 / 公众号头条  
> 风格锚点：一个钩子 + 一个方法论 + 一份可抄模板 + 一张可直接用的封面素材，1500-2500 字/篇  
> 发布平台：小红书（主） · 公众号 · 知乎 · 个人博客  
> 规模：2 个子系列共 35 篇

---

## 读者画像

| 项 | 内容 |
|---|---|
| 是谁 | 有技术背景 / 想变现的自媒体人；产品 / 设计 / 运营侧的深度读者 |
| 已经会 | 会刷小红书、有公众号、看得懂技术但不写代码 |
| 想要 | 学一套方法论 + 一份可抄模板，让下一篇内容 / 下一篇笔记有增量 |
| 不想看 | 「10 秒学会」「震惊体」「小白也能懂」这种打了但没打的文案 |
