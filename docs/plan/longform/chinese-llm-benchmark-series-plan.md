# 中文模型横评 · 同题实测 · 总规划

> ⏳ **候选系列 · 待二次筛选**（见 [`00-longform-shortform-focus.md`](../00-longform-shortform-focus.md)）  
> 固定「同题多模型」栏目，跟国内模型迭代；素材可再生，适合周更/双周更。
>
> 姊妹系列：`ai-series-plan.md` · `ai-cost-billing-series-plan.md` · `new-site-case-studies-series-plan.md`
>
> 本系列定位：要在 DeepSeek / Kimi / Qwen / GLM / Doubao 等之间做选型的开发者与内容人  
> 核心承诺：**同一套题目、同一套评分表**；不写厂商软文  
> 风格锚点：题目 → 各模型原文节选 → 评分表 → 适用场景结论，2000–3000 字/篇  
> 发布平台：个人博客（主）· 知乎 · 掘金 · 即刻 · 公众号  
> 规模：常设栏目 **首季 16 期** + 可无限续季

## 评分表（全季锁定，季末可修订 v2）

| 维度 | 权重 | 说明 |
|---|---|---|
| 正确性 | 30% | 事实 / 代码可运行 / 指令遵循 |
| 中文质量 | 15% | 流畅、少机翻腔 |
| 格式服从 | 15% | JSON / 表格 / 字数限制 |
| 推理过程 | 15% | 是否可检查，而非只给答案 |
| 拒绝与安全 | 10% | 该拒时拒、不该拒时不滥拒 |
| 成本感 | 15% | 同等质量下的单价与速度（注明测时定价） |

每期至少 **3 个模型**；注明版本号、日期、温度、是否联网。

## 首季 16 期题库

### 基础能力（1–4）

| 期 | 题目类型 |
|---|---|
| 1 | 栏目说明 + 评分表 + 冒烟题（简单指令遵循） |
| 2 | 长文摘要：同一篇中文技术文 |
| 3 | 结构化输出：严格 JSON Schema |
| 4 | 翻译：中英互译（含术语） |

### 代码与工具（5–8）

| 期 | 题目类型 |
|---|---|
| 5 | 读报错修 Bug（同一段 TypeScript） |
| 6 | 从零写小函数 + 单测 |
| 7 | SQL / 数据提问 |
| 8 | Tool Calling 描述：写好 vs 写坏 schema 谁更稳 |

### 推理与检索感（9–12）

| 期 | 题目类型 |
|---|---|
| 9 | 多步数学 / 逻辑（展示过程） |
| 10 | 给定材料回答（模拟 RAG，禁用电厂知识） |
| 11 | 矛盾材料：能否指出冲突 |
| 12 | 长上下文找针（同一 haystack） |

### 产品场景（13–16）

| 期 | 题目类型 |
|---|---|
| 13 | 客服：政策问答 + 升级人工 |
| 14 | 内容：小红书/公众号提纲（注明品味主观项） |
| 15 | Agent 规划：拆任务但不执行工具 |
| 16 | 季终横评：总表 + 场景选型建议 |

## 每期结构模板

```
【题目原文】完整可复制
【环境】模型版本 · 日期 · 参数 · 是否联网
【输出摘录】各模型关键段落（全文可放附录/折叠）
【评分表】打分 + 一句话评语
【结论】谁适合什么场景；并列或「本题无胜者」允许
【复现】读者怎么自己跑一遍
```

## 续季机制

- 新模型发布 → 插入「加赛」期，不打断题号可用「S2E1」
- 定价大变 → 出成本附刊，链到 `ai-cost-billing-series-plan.md`
- 评分表大改 → 必须新开一季，避免和旧分混谈
